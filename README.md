# cse1106-final
Project: Smart Classroom Comfort Monitor
Programming Language: C
Hardware: Raspberry Pi

1. Project Description
Our team selected the Smart Classroom Comfort Monitor. This system will allow users to enter classroom temperatures and determine whether the environment is within an acceptable range of 68°F–76°F. A warning LED will turn on when the temperature is outside the acceptable range.

2. Team Responsibilities

Luis — Hardware Development

Set up the Raspberry Pi.
Connect the LED, resistor, and breadboard.
Configure the GPIO connection.
Test the hardware components.

Niamah  — Software Development

Write the C program.
Check temperature readings and display NORMAL or WARNING.
Calculate the average temperature.
Save readings and statuses to a file.
Allow users to change the acceptable temperature range.

Both Members
Test and debug the system.
Maintain the GitHub repository.
Prepare documentation and the final demonstration.




3. Development Plan
Our team will begin by creating the GitHub repository and documenting the requirements. Next, we will develop the C program and assemble the Raspberry Pi LED circuit. Finally, we will integrate the software and hardware, conduct testing, and prepare the final demonstration.
